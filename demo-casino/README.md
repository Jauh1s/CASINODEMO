# Royal Demo Casino — DEMO / PLAY MONEY
A fictional play-money casino (Next.js + TypeScript + Tailwind). Virtual credits only, no monetary value, no payments.

## Run locally
    npm install && npm run dev      # http://localhost:3000

## Publish on GitHub Pages
1. Create a new GitHub repo and push this folder to the `main` branch.
2. In the repo: Settings → Pages → Source: **GitHub Actions**.
3. The workflow in `.github/workflows/deploy.yml` builds and deploys automatically.
4. Your game will be live at `https://<username>.github.io/<repo-name>/`.
